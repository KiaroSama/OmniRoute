Akwụkwọ a bụ ntụaka kachasị ikike maka ọnụ ụzọ ogo CI niile dị na OmniRoute.
Ọ na-akọwa ọnụ ụzọ ọ bụla, ihe ọ na-enyocha, ọrụ CI ọ na-arụ n'ime ya, ma ọ na-eji
ntọala ratchet ma ọ bụ iwu ngafe/ọdịda, yana ma ọ na-egbochi build ka ọ bụ naanị ndụmọdụ.

Maka nchịkọta dị mkpirikpi na iwu allowlist, lee ngalaba "Quality Gates & Ratchets"
dị na `AGENTS.md`. Maka nyocha dị mkpa, nhazi ọkwa ntozu-oke, na atụmatụ mmegharị
nke otu sistemụ ahụ na-adabereghị na ngwá ọrụ ọ bụla, lee
[Quality Gate Playbook](../ops/QUALITY_GATE_PLAYBOOK.md).

## Ndepụta ọnụ ụzọ na profaịlụ mmejuputa

### Nnabata onye ndọrọndọrọ

Usoro ọrụ CI na Quality Gates nke ọ bụla na-ewepụta mkpebi kwụsiri ike: `Gate / CI` na
`Gate / Quality`. Iwu nnabata ha nwere ụdị mbipụta na-edepụta ọrụ upstream niile
dị ka ihe a chọrọ ma ọ bụ ndụmọdụ. Ọrụ achọrọ nke metụtara ọnọdụ ahụ ga-aga nke ọma: nsonaazụ
na-efu efu, a kagburu, a mafere, ka na-echere na nke amaghị enweghị ike igosi PASS. Nhazi ziri ezi
nke bụ naanị docs ma ọ bụ naanị catalog nwere ike ime ka lane koodu ghara ịdị mkpa;
draft PR abụghị onye ndọrọndọrọ anabatara. Label `hotfix` anaghị ewepụ mkpa ihe akaebe.

Usoro ọrụ abụọ ahụ na-ekpuchi PR na push gaa na branch main/release, dispatch aka na
event merge-group. Push, dispatch na merge-group na-eme nhọrọ zuru ezu. Fork
na merge group na-eji hosted runners maka ọrụ ndị gaara ahọrọ self-hosted
runners; a ga-enyocharịrị na ikike hosted zuru oke tupu rollout.

Receipt JSON ọ bụla na-akọwapụta SHA e mere checkout ya, workflow run na attempt.
CLI na-ajụ ma checkout/event SHA ekwekọghị. Nnwale workflow na-ejikọ ndị so na policy
na ndepụta `needs` nke ọrụ verdict ka lane ọhụrụ ma ọ bụ nke ewepụrụ ghara ịla n'iyi na nzuzo.
Receipt ndị ahụ na-ekpuchi workflow nke ha, ọ bụghị publication, deployment, ma ọ bụ ihe dị n'ime
scanner advisory dị adị. Ime ka aha check abụọ ahụ rụọ ọrụ n'ime iwu branch bụ
mgbanwe nchịkwa dị iche; ịgbakwunye ọrụ ndị a anaghị echebe branch n'onwe ya.

### Ndepụta static scan

Ndepụta npm-alias nwere ụdị mbipụta na ndị so na static-scan dị na
`config/quality/gate-manifest.json`. Mee `npm run check:gate-manifest` iji nyochaa
aha script na command kpọmkwem megide `package.json`; mgbakwunye, mwepụ na
mgbanwe command na-eme ka ma local hook ma ọrụ change-classification dị na CI daa.
Alias abụghị ọrụ workflow, matrix instance ma ọ bụ test case: agaghị egosi ọnụ ọgụgụ ndị a
dị ka a ga-asị na ha nwere ike dochie ibe ha.

Jiri `npm run quality:scan -- --list` ma ọ bụ `npm run quality:scan:fast -- --list`
iji nyochaa alias ndị ahọpụtara n'emeghị ha. Runner na-akpọ
npm entrypoint, ya mere a na-echekwa runtime ya (gụnyere Bun ebe ahaziri ya).
Manifest na-edekọ alias ndị na-anọghị na profaịlụ ndị ahụ dị ka ndị a na-akpọ iche, ma
a machibidoro command mmezi iwu n'ime profaịlụ scan read-only.

Profaịlụ ndị a na-ekpuchi naanị static scan. Ha anaghị akwado product tests,
coverage, packaging, external checks ma ọ bụ nnabata release zuru ezu nke onye ndọrọndọrọ.
Nnabata workflow na-eji `config/quality/admission-policy.json` ejikọrọ na
`scripts/quality/admission-verdict.mjs`. Profaịlụ release-observer ka dị iche;
nyochaa check na receipt ndị metụtara ha n'onwe ha. Ndepụta nkọwa
dị n'okpuru bụ ntụaka, ọ bụghị ihe akaebe na gate rụrụ ọrụ n'ezie.

Script dị n'okpuru `scripts/check/` (policy gates) na `scripts/quality/` (ratchet engine).
Ezi isi mmalite CI bụ `.github/workflows/ci.yml`.

### Ụzọ ngwangwa Release PR (`quality.yml`)

`.github/workflows/quality.yml` na-akwado CI na PR main/release, push
protected-branch, dispatch na merge group. PR na-eji fast checks a nyochara site na path. E wepụrụ
duplicate build agbanyụrụ kpamkpam; ezigbo check build/package/boot ka dị na CI.

| Ọrụ                                              | Oke                                                                                                                                                                                                 | Na-egbochi       |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------- |
| `Docs Gates (fast-path)`                         | PR docs/koodu; ntụaka API docs na docs-all                                                                                                                                                          | Ee               |
| `Fast Quality Gates`                             | PR koodu; static checks, typecheck, dashboard typecheck, unit tests emetụtara                                                                                                                       | Ee               |
| `Forgotten sibling tests`                        | PR koodu; a na-esochi module gbanwere ruo static consumers na candidate sibling tests; a na-akọ path barrel na dynamic-import dị ka advisory diagnostics, yana exception allowlist e zoro aka na ya | **Ndụmọdụ**      |
| `Vitest (fast-path)`                             | PR koodu; suite vitest ngwa ngwa                                                                                                                                                                    | Ee               |
| `Unit Tests fast-path`                           | PR koodu; suite unit nwere shard 4                                                                                                                                                                  | Ee               |
| `No new ESLint warnings`                         | PR koodu; nche lint maara suppression                                                                                                                                                               | Ee, gụnyere fork |
| `Merge integrity (changelog + generated skills)` | PR na-abụghị draft; changelog na sync nke skill e mepụtara                                                                                                                                          | Ee, gụnyere fork |

#### Akụkọ Forgotten sibling tests

`npm run check:forgotten-sibling-tests` na-ejigharị import resolver dị n'azụ map test-impact.
Maka production module ọ bụla gbanwere, ọ na-akọ chain doro anya na-agbanwekwaghị agbanwe nke
`changed module/symbol -> static consumer -> candidate sibling test` mgbe candidate
test adịghị na diff pull-request. A na-edobe nchịkọta Markdown na nsonaazụ JSON dị ka
artifact workflow `forgotten-sibling-tests` maka calibration tupu rollout ọ bụla na-egbochi ihe.

Mbupụgharị barrel na mbubata dynamic bụ naanị nchọpụta mkpebi; ha anaghị emepụta nchọpụta
na-egbochi ihe. Mwepu ndị a tụlere dị na
`config/quality/forgotten-sibling-allowlist.json`. Ndenye ọ bụla ga-akpọrịrị consumer na candidate
test aha, nye ezi ihe kpatara ya kpọmkwem, ma jikọta issue ma ọ bụ pull request GitHub. Ndenye ndị ahazighị
nke ọma na-ada n'ụzọ mechiri emechi. Mwepu enweghị ike igbochi candidate test ehichapụla ma ọ bụ diff nke na-agbakwunye `.skip`/`.todo`;
ime ka assertion ghara isi ike na mkpuchi ndị ọzọ ka bụ ọrụ gate
`check:test-masking` nke na-egbochi ihe n'onwe ya.

#### `check-ui-value-drift` — gate ntụgharị ochie

Ọ na-achọpụta otu ndaghachi azụ i18n nke gate ndị ọzọ enweghị ike ịhụ site na nhazi: a na-edegharị value Bekee
ma ntụgharị ndị e si na Bekee _gara aga_ mepụta ka na-adị, nke mere na
ndị ọrụ na-abụghị ndị Bekee na-aga n'ihu ịgụ ederede e ji obi ike dee ma nke na-ezighị ezi ugbu a.

Nke a rutere n'ezie na mbipụta. E degharịrị `oauthModal.googleOAuthWarning` mgbe ihe enyemaka nbanye Antigravity
bịara (#5203); **locale 39 n'ime 43** ka nwere ederede na-agwa ndị na-ahụ maka sistemụ ka ha "detuo URL
zuru ezu ma mado ya n'okpuru" — usoro nke na-enweghị ike ịrụcha maka provider ahụ. A hụghị
ya ruo #8463 n'ihi na:

- `sync-ui-keys` na-emeju naanị key ndị **na-adịghị**, ọ naghị emeju ndị **ochie**;
- `check-ui-keys-coverage` na-agụta _ọnụnọ_ key, ya mere ntụgharị ochie na-enweta akara dịka nke e kpuchiri;
- `check-translation-drift` na-enyocha oyiri dokumenteshọn `docs/i18n/<locale>/**.md` —
  ọ naghị agụ `src/i18n/messages/*.json` ma ọlị. Ọ na-egbochi n'ime ọrụ `docs-sync-strict` kemgbe
  mmekọrịta ulang nke 2026-09: dezie core doc → `npm run i18n:run -- --files=<doc>` (n'ogo section, adịghị oke ọnụ).

**Na-eburu diff n'uche, ọ bụghị nke baseline na-akwado.** Ọ na-atụnyere `en.json` dị na merge base na working tree; maka key ọ bụla uru Bekee ya gbanwere, locale ọ bụla ka nwere ntụgharị a na-emetụghị aka abụrụla nke mgbe ochie. Nke a na-ama ụma **na-ajụ ụgwọ ọrụ ochie ka ọ ghara ịgbanwe** — diff enweghị ike igosi ụdị Bekee ochie ntụgharị dịteworo aka si na ya pụta, ya mere gate ahụ na-enyocha naanị ihe mgbanwe dị ugbu a metụrụ. Nhọrọ ọzọ (baseline hash maka key ọ bụla) ga-achọ faịlụ emepụtara nke dị ihe dịka ~600 KB, okpukpu 3 karịa baseline kachasị ukwuu dị ugbu a, ma na-agbanwegharị na PR i18n ọ bụla.

E nwere ụzọ abụọ iji mezuo ya:

1. melite ntụgharị ndị o metụtara, ma ọ bụ
2. tọọ ha ka ha bụrụ `__MISSING__:<Bekee ọhụrụ>` — runtime ga-eweta Bekee ahụ e doziri
   (`src/i18n/request.ts::deepMergeFallback`, #7258), key ahụ abanyezie n'ahịrị ntụgharị.

Ọ bụrụ na **ihe eriri ahụ pụtara** agbanweela, ọ ka mma **ịgbanwe aha key ahụ**: key ọhụrụ enweghị ike iketa ntụgharị mgbe ochie. Nke ahụ bụ usoro #8463 jiri.

```bash
npm run i18n:check-value-drift          # siri ike (nke CI na-agba)
npm run i18n:check-value-drift:warn     # naanị mkpesa
BASE_REF=origin/release/vX.Y.Z npm run i18n:check-value-drift
```

Ọ na-eji 0 apụ ma gosipụta `SKIP reason=base-unresolved` mgbe enweghị ike ịgụ base catalog (shallow clone na-enweghị base ref), dịka `check-openapi-breaking`.

**Ụdị koodu ọhụrụ (Clean-as-You-Code) — kemgbe 2026-08-30, naanị ụzọ ọsọ ọsọ PR**

kwa faịlụ):

## Iwu Ndepụta Ikike

Ọnụ ụzọ nyocha ọ bụla nke na-agaghị ada n’ihi mmebi ndị dịbu adị na-eji ndepụta ikike a kpọchiri akpọchi
(dịka, `KNOWN_STALE_DOC_REFS`, `KNOWN_MISSING`, `KNOWN_RAW_SQL`). Iwu ahụ bụ:

**Dozie isi ihe kpatara nsogbu ahụ; jiri ndepụta ikike naanị mgbe mmebi ahụ dịbu adị ma
enweghị ike idozi ya n’otu PR ahụ.**

Mgbe ị na-agbakwunye ntinye na ndepụta ikike:

1. Tinye nkọwa na-akọwa ihe mere e ji mee ya.
2. Rụtụ aka n’okwu nlekota ahụ (dịka, `// #3498 — Njirimara Phase 2, emebebeghị ya`).
3. Wepụ ntinye ahụ n’otu PR ahụ nke na-edozi mmebi ahụ — ntinye ochie nke na-anaghịzi
   egbochi mmebi na-arụ ọrụ bụkwa ntụpọ (mmanye iwu megide ntinye ochie nke 6A.3 ga-eme ka
   ọnụ ụzọ nyocha ahụ daa n’ihi ntinye ndepụta ikike na-enweghịzi ihe ọ metụtara ozugbo etinyere ya n’ọrụ).

**Etinyela** ntinye na ndepụta ikike iji mee ka ule gafee ngwa ngwa. Ọnụ ụzọ nyocha na-acha akwụkwọ ndụ ebe
ndepụta ikike na-aga n’ihu na-eto eto na-enye echiche ụgha banyere ịdịmma.

### Mgbe ọnụ ụzọ nyocha dara na PR gị

1. **Jiri nlezianya gụọ nsonaazụ ọnụ ụzọ nyocha ahụ** — ọ na-agwa gị kpọmkwem faịlụ ma ọ bụ akara nke
   mebiri iwu ahụ.
2. **Dozie mmebi ahụ** — ọtụtụ ọnụ ụzọ nyocha bụ nlele sistemụ faịlụ a kara aka nke na-agafe ozugbo
   koodu ahụ ziri ezi.
3. **Ọ bụrụ na mmebi ahụ dịbu adị** (ya bụ, ọ bụghị gị webatara ya mana ọnụ ụzọ nyocha ahụ
   amalitela ikpuchi ya): gbakwunye ntinye ndepụta ikike nwere nkọwa ihe kpatara ya na okwu nlekota.
4. **Ọ bụrụ na ọnụ ụzọ nyocha ahụ bụ ratchet** (mkpuchi, ịdọ aka ná ntị ESLint, mmegharị otu ihe ugboro ugboro, mgbagwoju anya):
   mgbanwe gị mere ka metrik ahụ ka njọ. Dozie nsogbu dị n’okpuru ya, ma ọ bụ (n’ọnọdụ pụrụ iche) mee
   `npm run quality:ratchet -- --update` ma ọ bụrụ na e bu n’obi mee mgbanwe ahụ ma a nabatara
