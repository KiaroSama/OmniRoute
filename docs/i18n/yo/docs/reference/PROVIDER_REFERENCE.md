## Awọn ẹka

- **Ọfẹ** — ipele ọfẹ pẹlu bọtini API (ti a tunto nipasẹ dasibodu)
- **Ko si-aṣẹ** — awọn ipari gbangba ti ko nilo bọtini tabi iwọle rara
- **OAuth** — ṣiṣan iwọle ti OmniRoute n ṣakoso, ko si bọtini API ti o nilo
- **Kuki wẹẹbu** — n fi ohun elo wẹẹbu olupese pamọ nipasẹ aṣẹ kuki
- **Bọtini API** — olupese ti o sanwo ti a tunto nipasẹ bọtini API (awọn kirẹditi ọfẹ le wulo)
- **Agbegbe** — nṣiṣẹ lori ẹrọ olumulo (Ollama, LM Studio, vLLM, ati bẹbẹ lọ)
- **Wiwa** — awọn olupese wiwa wẹẹbu
- **Ohun** — awọn olupese ohun nikan (TTS/STT)
- **Aṣoju oke** — awọn olupese ti o ṣe aṣoju si awọn olupese miiran
- **Aṣoju awọsanma** — awọn aṣoju koodu ti n ṣiṣẹ pẹlu (Codex Cloud, Devin, Jules)
- **Eto** — awọn olupese inu OmniRoute (loopback, ati bẹbẹ lọ)

Awọn afi afikun: `aworan`, `fidio`, `agbajo`, `ile-iṣẹ`, `fi sii/tunto`, `ti ara ẹni`.

`Ipe irinṣẹ` (nibiti o ti han): `abínibí` — API ipe iṣẹ gidi; `ti a farawe` — akojọpọ `awọn irinṣẹ` ti a farawe ni kiakia nipasẹ `webTools.ts` (awọn bulọọki `<tool>{...}</tool>` ti a ṣe atupale regex); `ko si` — `awọn irinṣẹ` ti wa ni sisọ silẹ ni idakẹjẹ lọwọlọwọ. Wo #7286.

Lo dasibodu ni `/dashboard/providers` lati mu ṣiṣẹ, tunto, ati idanwo olupese kọọkan.
