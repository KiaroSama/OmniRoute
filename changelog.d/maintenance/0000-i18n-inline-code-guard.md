- **i18n:** the translation pipeline treats inline code as a literal — the prompt now says so explicitly, and a chunk whose output loses any of the source's inline code spans (a translated error message, `MemoryHigh=4G` split in two, a dropped backtick that re-pairs the rest of the line) is rejected and retried instead of written; in the 2026-10-18 resync every pass had translated such literals in 7–12 locales.
