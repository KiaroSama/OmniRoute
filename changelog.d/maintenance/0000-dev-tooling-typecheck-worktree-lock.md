- **chore(dev):** two developer scripts replace shell recipes that every 2026-10 campaign session re-typed by hand. `scripts/dev/typecheck-touched.sh [--base <ref>] [file ...]` typechecks only the touched `.ts/.tsx` files through a temporary tsconfig (`extends ./tsconfig.json`, `types: ["node"]` so narrow includes stop inventing `TS2591 Cannot find name 'node:test'`), runs `tsc` under a 6 GB heap instead of the project-wide run that OOMs the shared devbox, keeps the full log under `_artifacts/typecheck-touched/`, always deletes the temp tsconfig, and exits 1 for errors in touched files, 2 for errors only in imported files or a tsc crash. `scripts/dev/new-worktree.sh` now serialises concurrent invocations on `<git-common-dir>/omniroute-new-worktree.lock` (flock, mkdir fallback, 600 s wait with a visible message) instead of racing on `.git/config` (exit 255), and rolls back the branch it created when `git worktree add` fails before the worktree exists, so a retry needs no manual `git branch -D`.
