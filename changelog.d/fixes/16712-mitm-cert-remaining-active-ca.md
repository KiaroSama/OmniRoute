- **fix(mitm):** `/api/settings/mitm` (cert download and `certExists`) and the AgentBridge repair step now use the active certificate, so repair no longer leaves the root CA trusted. "Regenerate cert" (the `cert/regenerate` endpoint, the dashboard action and `settings/mitm`) never changes the cert model any more: legacy installs get a new leaf, and root-CA installs get a rotated CA. The old CA is untrusted first, rotation is refused while the bridge runs, and the response says the new CA must be trusted ([#16712](https://github.com/diegosouzapw/OmniRoute/pull/16712))
