- **fix(api):** Prioritize chat and responses endpoints in `detectTestKind` and `classifyModelSupportedEndpoints` so multimodal chat models are not probed as audio transcription models or classified as specialty media surfaces. Previously, if a custom model had `audio-transcriptions` or media endpoints among its `supportedEndpoints`, `detectTestKind` checked audio transcription first and dispatched a test probe to `/v1/audio/transcriptions`, which rejected non-transcription providers with `Invalid transcription model: <model>. Use format: provider/model`. Chat capability now takes precedence during test detection and endpoint classification.
