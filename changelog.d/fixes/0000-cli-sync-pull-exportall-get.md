- **fix(cli):** `omniroute sync pull` works again. It sent `POST /api/db-backups/exportAll`, but that route only answers `GET` with a `.tar.gz` archive, so every run ended in `Error: 405`. The command now downloads the archive with `GET` and the local CLI credential (which the operator-only export check accepts), writes it to `[outPath]` or to the server's file name (owner-only permissions, never overwriting an existing file), and turns a 401/403/405 into a readable error instead of a bare status. The `--source/--merge/--replace/--dry-run` options were dropped: the route never supported them.
