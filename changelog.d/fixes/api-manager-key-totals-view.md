- **perf(api-manager):** load the per-key request, cost and last-used columns from a new `GET /api/usage/analytics?view=apiKeys` view that runs one grouped query, instead of the full all-time analytics report plus 1,000 call logs. On instances with a few hundred thousand `usage_history` rows the full report held the event loop for 10+ seconds on every API Manager visit, stalling all proxied streams; last-used times now also cover keys outside the newest 1,000 call logs.
