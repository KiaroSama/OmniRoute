- **fix(authz):** management credentials now take a real credential to obtain when login is disabled. With `requireLogin=false`, an anonymous caller could create an API key with the `manage` or `admin` scope, grant that scope to an existing key, regenerate or reveal a management key, or mint a CLI access token at any scope — and each of those credentials passes the always-protected tier (credential and log exports, shutdown). Those operations now need a dashboard session or the local CLI in every login mode, and a manage-scoped key keeps its `write` ceiling for CLI tokens with login off, as it already had with login on. Inference-only keys are unaffected: they are still created, edited, regenerated and revealed exactly as before.
