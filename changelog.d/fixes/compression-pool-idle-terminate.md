- **fix(compression):** terminate idle compression worker threads on eviction. `finish()` scheduled `remove(slot, false)`, so the idle timer only dropped the pool's reference and the `worker_threads` thread, its `MessagePort` and its private heap (~100 MB each) survived for the whole process lifetime — every successful chat request on the published 3.8.50 npm package leaked one more thread, invisible to `heapUsed`, until the host hit its memory cap. Ported from `release/v3.8.51` as an npm hotfix on top of 3.8.50 ([#13091](https://github.com/diegosouzapw/OmniRoute/pull/13091), [#14933](https://github.com/diegosouzapw/OmniRoute/issues/14933), [#11804](https://github.com/diegosouzapw/OmniRoute/issues/11804)) — thanks @anhtahaylove
