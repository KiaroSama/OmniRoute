- **fix(security):** `/api/oauth/kiro/auto-import` can no longer be opened to remote callers through the LOCAL_ONLY manage-scope bypass list. The route reads host-local Kiro credential files (kiro-cli data, `~/.aws/sso/cache`), so it now sits in the same never-bypassable set as the spawn-capable routes: `PATCH /api/settings` rejects it (and any broader prefix such as `/api/oauth/kiro/`) with `BYPASS_PREFIX_NOT_ALLOWED`, the runtime snapshot drops it from a stored bypass list, and the request-time check refuses it for a manage-scoped key from a non-loopback address.
