- **fix(usage):** stop bounded log/quota previews from retaining whole request bodies — `truncateLogString` (`open-sse/utils/requestLogger.ts`) and `truncatePreviewString` (`src/lib/usage/usageHistory/helpers.ts`) built their result from `String#slice()`, which V8 can represent as a `SlicedString` whose parent is the entire multi-megabyte source. Any retained 64 KB / 1200-char preview therefore kept the full request body alive. Both now flatten the result (Buffer round-trip), matching the `structuredClone` guard the completed-details path already uses. A cut that would keep a trailing high surrogate is shortened by one code unit first, so the round-trip does not replace a split pair with U+FFFD.
