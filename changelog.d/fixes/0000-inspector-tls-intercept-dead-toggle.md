- **fix(inspector):** removed the Traffic Inspector "TLS intercept" toggle, which never did anything. The HTTP_PROXY listener only CONNECT-tunnels HTTPS and nothing read the flag, yet the docs said turning it on would decrypt HTTPS bodies. `POST /api/tools/traffic-inspector/capture-modes/tls-intercept`, the `tlsIntercept` field of `GET /capture-modes`, the matching CLI command and the `INSPECTOR_TLS_INTERCEPT` env var are gone. The docs now say plainly that HTTP_PROXY mode records HTTPS as tunnel metadata only, and point to AgentBridge, Custom Hosts or TPROXY decrypt for body capture.
