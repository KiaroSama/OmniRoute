- **fix(sse):** some Cloudflare Workers AI models stream a digit as a JSON number (`"delta": {"content": 7}`). Only string content counted as text in the passthrough, so those chunks were dropped and the digits vanished from the reply («ABC123» came out as «ABC»). A finite numeric `delta.content` is now turned into its string before the chunk is forwarded, recorded or counted ([#16614](https://github.com/diegosouzapw/OmniRoute/pull/16614)) — thanks @pacocartones. Refs #16554.
