- **fix(mitm):** `bin/antigravity-bridge.mjs` now finds its certificate the way the AgentBridge server does. It used to read only `server.crt`/`server.key` from `CERT_DIR` or `$HOME/.omniroute/mitm`, so it ignored `DATA_DIR` and exited with "Certificate files not found" on root-CA installs (`ca.crt`/`ca.key`, the default model). It now reads `<DATA_DIR>/mitm` (with `CERT_DIR` still an explicit override), keeps the legacy leaf where one is active, signs a per-host leaf from the root CA otherwise (respecting `MITM_ROOT_CA_ENABLED`), and exits at startup with a mode-specific message when the files are missing ([#16724](https://github.com/diegosouzapw/OmniRoute/pull/16724)).
