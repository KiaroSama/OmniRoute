- **fix(api):** the dashboard model test works again with `REQUIRE_API_KEY=true` when the caller authenticates with a manage-scoped key, the CLI token or an `oma_` token instead of a dashboard cookie. The test calls the `/v1/chat/completions` and `/v1/responses` handlers in-process. Since #16403 those handlers check authentication themselves, so the anonymous internal request got `401 Authentication required`. Both internal requests now present the per-process self-loop bearer, which is never sent over the wire. They also send `x-omniroute-no-memory: true`, so the probe gets no injected memory or skills (#15306) — thanks @shipsfromrio
