- **fix(api):** a `null` JSON body made `POST /api/logs/detail`, `PATCH` and `PUT /api/settings` and `DELETE /api/providers` throw (`Cannot read properties of null`) and the request ended as a 500, and `POST /api/logs/detail` answered a string, a number or `true` body with a 200 that switched detailed logs off; they now answer 400 for a body that is not an object (`POST /api/logs/detail` also for malformed JSON, which was an unhandled rejection). Input validation, not a crash fix: other requests and the process are unaffected either way. ([#16671](https://github.com/diegosouzapw/OmniRoute/pull/16671)) — thanks @pacocartones.
