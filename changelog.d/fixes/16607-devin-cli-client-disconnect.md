- **fix(devin-cli):** a client disconnecting mid-stream no longer crashes the server. The executor kept calling `controller.enqueue()`/`close()` from the child's `close` handler after the response body was cancelled, which throws `ERR_INVALID_STATE` inside an event listener (an uncaught exception). The stream now defines `cancel()`, which stops the child and silences further writes ([#16607](https://github.com/diegosouzapw/OmniRoute/pull/16607)) — thanks @pacocartones.
