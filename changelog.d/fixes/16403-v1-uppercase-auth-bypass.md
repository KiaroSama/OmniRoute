- **fix(security):** close authentication bypass via uppercase path variants. The authz proxy matcher's custom regex groups (e.g. `/:v1seg([vV]1)/:path*`) do not reliably match uppercase aliases in production, so requests like `POST /V1/chat/completions` skipped the proxy and reached the dispatch layer with no API key (the route handlers performed no authentication of their own). The critical inference handlers (`chat/completions`, `completions`, `messages`, `responses`, `responses/[...path]`) now enforce `enforceClientApiRouteAuth` directly as defense-in-depth. ([#16403](https://github.com/diegosouzapw/OmniRoute/pull/16403))
